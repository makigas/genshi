# Changelog for @makigas/genshi-svelte

## trunk

Genshi is now a monorepo. @makigas/genshi-svelte has been moved to
https://github.com/makigas/genshi. Genshi is now released under the terms of
the AGPL-3.0-or-later license.

Removed:

- genshi-svelte docs, because they are now part of the docs app in the monorepo.

## 1.0.0-alpha.1

This is the first version. I started counting versions in this repository at 1.0.0-alpha.1, to keep
the version number in sync with the one in @makigas/genshi.

Added:

- Svelte components for the components defined in @makigas/genshi.

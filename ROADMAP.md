# Roadmap and tasks

## Things to do before 1.0.0-alpha.3

- Fix packaging of SCSS, in order to support SCSS customization.
- Unify prefixes in class names and properties: --genshi -> --gs, Genshi -> Gs
- New components: card (Genshi.Card) and pill (Genshi.Pill)
- Montserrat is not part of core anymore (but it will stay on docs).
- Theme level default and unification of font-size.
- Theme level default and unification of border-radius.
- Theme level default and unification of spacing (padding, margin, gap).
- Sizes, radius and family can be customized when importing SCSS.

## Things to do before 1.0.0-alpha.4

- New components: Genshi.Alert
- Refactor Form API (Genshi.Form + Genshi.Control)
- Svelte: Defaults component, but this depends on the unification for alpha.3.
- Astro and React rendition

## Things to do before 1.0.0

- Consolidate docs (specially for the Install part on renditions.)
- Design patterns for stuff like "how to use color", "tone".
- Fully migrate makigas.es to @makigas/genshi.
